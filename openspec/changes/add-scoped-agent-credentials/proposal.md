## Why

Agent invite redemption distributes the operator key. Curated knowledge permissions need recorded caller identity before the server can separate proposal submission from approval or accepted content editing.

## What changes

Issue durable scoped agent credentials, bind REST, MCP, and WebSocket callers to recorded identities, and restrict credential and invite administration to the operator. OAuth uses its stable grant ID and supports explicitly requested knowledge capabilities. Existing OAuth grants receive no new scopes.

## Impact

Issue #380 is a prerequisite for #369. Ordinary note tools remain available according to explicit notes scopes and vault grants. Folder/note policies and proposal endpoints remain tracked in their implementation issues.
