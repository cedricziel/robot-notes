## Why
Curated knowledge requires human review, block comments, and reversible accepted changes within the existing note editor.

## What Changes
- Add explicit review, comments, history, and policy controls to note screens.
- Keep pending proposals outside the normal accepted note view.
- Respect server-reported permissions and refresh after stale decisions.

## Impact
- Affected specs: knowledge-review-ui
- Affected code: Flutter note screen and API client
- Dependencies: curated permissions and block proposals
