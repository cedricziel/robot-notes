## Why
Entry corrections can append a new claim when the previous entry is ambiguous, and multiline entries can be only partly replaced. Agent adapters also need honest institutional proposal outcomes and source lineage without a competing fact store.

## What Changes
Pin the Hermes bridge that supplies the exact committed previous entry. Share a span-based correction planner across immediate and durable paths. Query effective permissions and submit curated writes as proposals, with accepted block identities, exact versions, supersession references, and supplied source coordinates. Report unmanaged personal provenance as unknown.

## Impact
Hermes provider, REST client, native write schemas, operation health, and prepared-operation migration. Ordinary personal write defaults remain available. No new knowledge store or invented human role.
