# Robot Notes Privacy Policy

The Robot Notes app does not collect any data.

- No analytics, no tracking, no advertising identifiers.
- No accounts with us. The app talks only to the robot-notes server you
  configure yourself, using the URL and API key you enter on first launch.
- Notes you read and write are stored on that server, which you operate.
  They never pass through our servers; we don't have any.
- The server URL and API key are stored in your device's system keychain and
  are never sent anywhere except to that server.

If you have questions, open an issue at
https://github.com/cedricziel/robot-notes/issues.
